# LiSKI - Light and Secure Knowledge Injection

## Quick Start

### Installation
Install LiSKI via pip:
```
Download and Unzip Repository
cd LiSKI/
 
```

### Datasets
Download ChEBI20 dataset via \url{https://github.com/blender-nlp/MolT5/tree/main/ChEBI-20_data}, place it under the `datasets`.
